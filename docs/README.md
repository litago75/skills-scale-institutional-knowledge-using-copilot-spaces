# OctoAcme Project Management Documentation

## Overview
OctoAcme runs projects with a lightweight, repeatable approach that helps teams stay aligned from idea to release. The process is built around a few core principles:

- **Customer-first**: focus on customer value, usability, and measurable outcomes.
- **Iterative delivery**: ship in small, testable increments and learn quickly.
- **Clear ownership**: assign accountable owners for outcomes, delivery, and decisions.
- **Data-informed decisions**: use metrics, evidence, and feedback to guide trade-offs.
- **Psychological safety**: create space for candid feedback, learning, and continuous improvement.

Use this README as the central starting point for the OctoAcme project management process library.

## Guidance for New Team Members
- Start with the [Project Management Overview](./octoacme-project-management-overview.md) to understand the lifecycle, roles, and operating principles.
- If you are joining a new initiative, review the [Project Initiation Guide](./octoacme-project-initiation.md) and [Project Planning](./octoacme-project-planning.md) documents first.
- For day-to-day delivery, keep the [Execution & Tracking](./octoacme-execution-and-tracking.md) and [Risk Management & Communication](./octoacme-risks-and-communication.md) guides close at hand.
- Before launch, use the [Release & Deployment Guide](./octoacme-release-and-deployment.md) to confirm readiness and rollback planning.
- After milestones or releases, use the [Retrospective & Continuous Improvement](./octoacme-retrospective-and-continuous-improvement.md) guide to capture learnings and improvements.
- Refer to [Roles & Personas](./octoacme-roles-and-personas.md) when you need clarity on responsibilities and collaboration expectations.
